# Security policy

## Supported versions

Only the `main` branch is maintained. Fixes are not backported.

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub:
**Security → Report a vulnerability** on this repository
([direct link](https://github.com/a-3isa/Mosque-Control-System/security/advisories/new)).

Please do not open a public issue for a security problem.

Include what you can of:
- the sketch, header or Firebase path affected;
- steps to reproduce, or a proof of concept;
- the impact you expect.

I aim to acknowledge reports within a week. Once an issue is confirmed, a fix is
prepared on a private branch and you are credited in the advisory unless you prefer not to be.

## Scope

In scope: the firmware in this repository.

Out of scope: the Flutter app (not in this repository), Firebase itself, and findings
that need physical access to a board.
